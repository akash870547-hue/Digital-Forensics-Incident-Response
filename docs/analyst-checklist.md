# DFIR Analyst Checklist

## Triage

- [ ] Define scope and affected assets
- [ ] Record case ID and collection time
- [ ] Preserve volatile evidence where operationally appropriate
- [ ] Isolate affected systems when containment is authorized
- [ ] Record evidence hashes

## Analysis

- [ ] Establish initial access hypothesis
- [ ] Reconstruct process lineage
- [ ] Review PowerShell and script execution telemetry
- [ ] Review persistence mechanisms
- [ ] Review network connections
- [ ] Review file creation/modification activity
- [ ] Build a normalized timeline
- [ ] Extract and classify IOCs
- [ ] Map findings to ATT&CK techniques

## Reporting

- [ ] Separate facts from analyst assessment
- [ ] State confidence for major findings
- [ ] Document evidence provenance
- [ ] List investigative gaps
- [ ] Provide containment, eradication, and recovery actions
- [ ] Validate the final report against the evidence
