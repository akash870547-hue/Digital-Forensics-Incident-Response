# Evidence Package

This folder contains **synthetic, non-malicious** forensic artifacts created for training.

## Files

### windows-events.csv

Contains Windows-style process, PowerShell, and file-system events.

### sysmon-events.csv

Contains Sysmon-style process and network telemetry.

## Handling Notes

- No real customer data is present.
- IPs/domains/hashes are fabricated.
- Log messages are intentionally simplified.
- These artifacts are suitable for parser development and timeline practice.
