# Security and Evidence Handling

This repository is a public DFIR training project.

## Do Not Upload

Never commit:

- Real forensic images or memory dumps
- Real customer or employee information
- Passwords, tokens, API keys, session cookies, or credentials
- Unredacted email exports
- Private network captures
- Evidence from an active investigation without authorization

Use synthetic or explicitly sanitized data for examples.

## Reporting a Problem

For code or documentation issues, open a GitHub issue without attaching sensitive evidence.

For any real-world incident, use the organization's approved incident-response and evidence-handling process rather than this repository.
